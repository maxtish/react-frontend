# 🚀 Full-Stack Проект: Python API (FastAPI) + React

Единая экосистема, развернутая на сервере Hetzner (CX23), состоящая из независимых сервисов. Бэкенд построен по профессиональной слоистой архитектуре с использованием ORM Prisma.

## 🏗 Архитектура и структура папок

Все проекты лежат в родительской директории `~/workspace/`.

```text
workspace/
 ├── python-backend/         # 🐍 Python + FastAPI + Prisma (API для веба)
 │    ├── dev.db             # База данных SQLite
 │    ├── venv/              # Виртуальное окружение Python
 │    ├── prisma/
 │    │   └── schema.prisma  # Схема таблиц БД
 │    └── app/               # 📦 Слоистая архитектура API
 │        ├── routers/       # HTTP-контроллеры (прием запросов)
 │        ├── services/      # Бизнес-логика (работа с базой)
 │        ├── schemas/       # Pydantic-модели (валидация данных)
 │        ├── database.py    # Подключение к БД
 │        └── main.py        # Точка входа бэкенда
 │
 └── react-frontend/         # ⚛️ React + Vite + TS (Веб-интерфейс)
      ├── src/
      │   ├── api/           # Функции общения с бэкендом (fetch)
      │   ├── types/         # TypeScript интерфейсы
      │   └── App.tsx        # Главный компонент UI
      └── vite.config.ts     # Настройки сборщика и прокси (/api -> 8000)
```

## 🛠 Разработка в VS Code (Dev Mode)

Для удобной работы откройте родительскую папку `workspace` в VS Code. Откройте два терминала (через плюсик) для параллельного запуска серверов разработки. Порты автоматически пробросятся на ваш локальный ПК.

### 1. Запуск Python API (Бэкенд)
В первом терминале:
```bash
cd ~/workspace/python-backend
source venv/bin/activate
uvicorn app.main:app --reload
```
* 🌍 Локальный адрес: `http://localhost:8000`
* 📖 Документация Swagger (тестирование API): `http://localhost:8000/docs`

### 2. Запуск React (Фронтенд)
Во втором терминале:
```bash
cd ~/workspace/react-frontend
npm run dev
```
* 🌍 Локальный адрес: `http://localhost:5173` (Все запросы на `/api` внутри React автоматически уходят на порт 8000).

## 🚀 Обновление на сервере (Production Mode)

Когда код проверен локально и готов к публикации в интернет по белому IP.

### Обновление Фронтенда (React)
Фронтенд нужно скомпилировать и положить в папку веб-сервера Nginx:
```bash
cd ~/workspace/react-frontend
npm run build
cp -r dist/* /var/www/react-app/
```
*(Применяется мгновенно, перезагрузка процессов не нужна)*

### Обновление Бэкенда (Python)
Бэкенд крутится в фоне под управлением PM2. Достаточно перезапустить процесс:
```bash
pm2 restart python-api
```

## 📝 Шпаргалки по инструментам

### 🗄 Prisma (База данных)
Если вы изменили файл `prisma/schema.prisma` (добавили новые колонки или таблицы), выполните в папке `python-backend` с включенным `venv`:
```bash
# 1. Синхронизировать БД с новой схемой (создать таблицы)
prisma db push

# 2. Сгенерировать обновленные типы для Python
prisma generate
```

### ⚙️ PM2 (Управление процессами)
PM2 следит, чтобы Node.js бот и Python API работали 24/7 и сами запускались при сбоях.
```bash
pm2 list                 # Показать таблицу всех процессов
pm2 logs                 # Смотреть все логи в реальном времени (выход: Ctrl+C)
pm2 logs python-api      # Смотреть логи только бэкенда
pm2 restart python-api   # Перезагрузить бэкенд
pm2 restart <имя_бота>   # Перезагрузить бота
pm2 save                 # Сохранить текущий список процессов для автозапуска
```

### 🌐 Nginx (Веб-сервер)
Nginx отдает статику React и проксирует `/api` в Python. 
* Конфиг находится по пути: `/etc/nginx/sites-available/react-app`
* После изменения конфига нужно выполнить:
```bash
nginx -t                 # Проверить конфиг на ошибки
systemctl restart nginx  # Перезапустить Nginx
```
